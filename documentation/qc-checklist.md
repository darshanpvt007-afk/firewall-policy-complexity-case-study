# Quality Control Checklist (Gate G5)

## Academic
- [ ] 15 or more references, all Verified = Yes
- [ ] 8 or more peer-reviewed or original standards references
- [ ] IEEE numbered style used consistently
- [ ] Part A section order matches Guidelines §2 exactly
- [ ] Part A is 4–6 pages excluding references
- [ ] Literature review organised by theme; every theme has agree / disagree / gap
- [ ] Our own critical inference is clearly visible
- [ ] Every important claim, statistic or comparison is cited

## Technical
- [ ] VLANs, trunks and routing verified (Stage 0)
- [ ] Every ACL entry traces to a requirement ID
- [ ] All tests run at every stage; Actual column complete
- [ ] Commands copied from real device output, not retyped

## Evidence
- [ ] Every important step has a config screenshot, a result screenshot and a caption
- [ ] Screenshots match the saved `.pkt` and config files
- [ ] Comparison table and chart present

## Integration
- [ ] Part A motivates Part B; Part B tests Part A claims; Part C compares the two
- [ ] Part C is about ½–1 page and answers all 3 Guidelines questions
- [ ] No claim that ACLs are equivalent to Zero Trust, or that Packet Tracer equals a production firewall

## Originality and submission
- [ ] All prose rewritten by team members; no unedited AI text
- [ ] Similarity index below 15% (record the tool and the score)
- [ ] Title page has team name, topic, member names and registration numbers
- [ ] Individual Contribution Statement attached
